# WordPress Auto Post Generator
# Quick Start Guide

## Step 1: Install Python
1. Download Python 3.8 or later from [python.org](https://www.python.org/downloads/)
2. Run the installer
3. **Important**: Check "Add Python to PATH" during installation

## Step 2: Prepare Project Files
1. Create a new folder for the project
2. Place these files in the folder:
   - `create_post_gui.py`
   - `wordpress_auto_post.py`
   - `requirements.txt`

## Step 3: Install Required Packages
1. Open Command Prompt (Press Windows + R, type "cmd", press Enter)
2. Navigate to your project folder:
   ```
   cd path\to\your\project\folder
   ```
3. Install requirements:
   ```
   pip install -r requirements.txt
   ```

## Step 4: Run the Application
1. In the same Command Prompt window, run:
   ```
   python create_post_gui.py
   ```

## Using the Application
1. Enter your post title in the "Post Title" field
2. Click "Preview Content" to see the generated content
3. If satisfied, click "Generate Post" to publish
4. Check the status area for results

## Troubleshooting
If the application doesn't start:
- Make sure Python is installed correctly
- Verify all required files are in the folder
- Check if requirements are installed
